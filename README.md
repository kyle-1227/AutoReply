# AutoReply

面向店铺运营的商品评价回复工具，通过 Edge 侧边栏管理评价素材、回复任务和待人工清单。

**当前版本：0.3.1 · 本机前端演示。** 使用原生 HTML、CSS 和模块化 JavaScript，无运行依赖、开发服务器或构建步骤。任务处理和英语回复仍在本机模拟；源码已提供独立 LLM 请求模块，尚未连接评价任务。真实店铺评价采集、回复发布、媒体理解和按商品加载上下文尚未接入。

## 已有功能

| 功能 | 说明 |
| --- | --- |
| 评价输入 | 支持纯文字、纯附件，以及文字与图片／视频组合；可点击选择、拖拽和多文件添加 |
| 素材预览 | 图片缩略图、浏览器视频播放器、文件名与大小展示、素材移除和重新选择 |
| 任务控制 | 按添加顺序逐条模拟，运行期间新增的评价继续纳入；支持立即暂停、继续和结束 |
| 评价队列 | 当前评价单独显示正文、素材和生成回复；“剩余评价队列”只列待处理项，已完成与待人工另列，支持展开详情和筛选 |
| 待人工清单 | 通过手动标记或演示样本，将需要人工处理的评价与原因单独展示 |
| 产品资料 | 保存产品名称、可选 SKU 和资料正文，支持增删改、跨窗口同步及编辑冲突提示 |
| 页面绑定 | 开始后固定来源标签页和完整网址，切换其他标签页不改变处理目标 |
| 多窗口运行 | 同一窗口最多占用一个任务，不同窗口可运行独立任务 |
| 悬浮入口 | 挂起或关闭侧边栏后，浮标跟随本窗口当前普通网页，显示进度与待人工数量，点击返回原任务 |
| 本机恢复 | 分别保存任务、回复和表单草稿，支持手动领取保存记录及一次性旧版记录导入 |

## 安装

需要桌面版 **Microsoft Edge 142 或更新版本**。项目已在 Windows 的 Edge 155 中进行安装与交互检查。

先获取源码：

```powershell
git clone https://github.com/kyle-1227/AutoReply.git
cd AutoReply
```

也可以在本仓库点击 **Code → Download ZIP** 后解压。

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 开启“开发人员模式”，选择“加载已解压的扩展”。
3. 选择项目中的 **`extension` 文件夹**，该文件夹直接包含 `manifest.json`。
4. 在扩展菜单中将 AutoReply 固定到工具栏。
5. 前往需要处理评价的普通网页，点击 AutoReply 图标打开侧边栏。

安装和运行插件无需安装 Node.js。详细操作及更新步骤见根目录 [安装说明.md](安装说明.md)。

## 开始一次演示

1. 在侧边栏点击来源页标题，展开并核对完整网址。
2. 点击“载入演示评价”，或在“添加评价”中输入文字、添加图片／视频。文字与附件至少提供一项。
3. 点击“开始演示”，任务开始占用本窗口并绑定来源页。
4. 可以继续添加评价、切换标签页，或点击“挂起”收起侧边栏。
5. 需要人工处理的评价保留在“待人工”页；所有可自动处理的评价完成后，本轮结束并释放窗口。

产品资料入口位于右上角的“添加产品资料”。当前资料库供前端管理使用，尚未参与回复生成。

## 任务运行规则

| 操作或事件 | 结果 |
| --- | --- |
| 只打开插件 | 展示准备使用的来源页，尚未占用窗口 |
| 开始任务 | 固定任务 ID、来源标签页、窗口和完整网址 |
| 立即暂停 | 取消当前步骤，保留进度和窗口占用；继续时重新处理当前未完成项 |
| 挂起、原生 X、切换标签页 | 原任务保持当前状态，运行中的任务继续推进 |
| 同窗口其他标签页重复打开 | 显示“此窗口正在使用”，可点击“返回任务页” |
| 同一完整网址刷新 | 等待来源页恢复后接续，已完成评价保留 |
| 来源换网址、关闭或移到其他窗口 | 结束任务、释放占用并保存记录 |
| 自动完成或点击“结束任务” | 释放窗口，保留已完成结果和待人工评价 |
| 完全退出浏览器或重新加载扩展 | 未完成记录等待在明确的目标页手动恢复 |

浏览器内部页面、扩展商店等受保护页面可能无法显示浮标，原任务仍保留，可通过工具栏返回。任务推进依赖浏览器、电脑和来源页保持可用。

## 数据与窗口隔离

- 评价队列、示例回复、处理记录、评价草稿和产品表单草稿按任务分别保存。
- 图片／视频原文件及预览地址只保留在当前面板会话中；关闭后保留附件信息，重新打开需要重新选择文件才能预览。
- 产品资料库在同一浏览器个人资料内共享；保存时检查版本，避免其他窗口的旧编辑覆盖新资料。
- 不同窗口用于隔离任务。普通新窗口仍共享网站登录状态，不同店铺账号需要独立浏览器个人资料或已有隔离环境。
- 浏览器重启后，可在目标页打开插件，通过“保存的任务记录 → 恢复到此页”领取已有记录，再手动开始。

## 独立 LLM 请求模块

`extension/llm-client.js` 导出 `requestLlm`，使用原生 `fetch` 请求 OpenRouter 的 Chat Completions API。它负责一次非流式请求，不依赖 DOM、插件消息、任务或存储。评价如何组装、使用哪个模型、模型输出正文还是 JSON，均由调用方决定。

```js
import { requestLlm } from "./extension/llm-client.js";

// Node.js 调用示例；Key 从本机环境读取，不写入源码。
const response = await requestLlm({
  apiKey: process.env.OPENROUTER_API_KEY,
  model: "anthropic/claude-haiku-5.5",
  messages: [{ role: "user", content: "Reply with OK." }],
  parameters: { max_tokens: 2048 },
});
```

本机 Key 填写在项目根目录的 `.env` 中：`OPENROUTER_API_KEY=你的Key`。该文件已被 Git 忽略，不包含在插件安装包中。运行 Node.js 调试脚本时使用 `--env-file=.env` 加载，再通过 `process.env.OPENROUTER_API_KEY` 传入请求函数；浏览器扩展不会自动读取根目录的 `.env`。

| 参数 | 说明 |
| --- | --- |
| `apiKey` | 必填，由调用方传入，模块不保存 |
| `model` | 必填，调用方明确选择的模型 ID |
| `messages` | 必填，已组装好的非空消息数组，内容原样发送 |
| `parameters` | 可选，普通对象，透传模型生成参数；不能包含 `model`、`messages`、`stream` |
| `signal` | 可选，调用方提供的 `AbortSignal`，可在请求及读取响应期间取消 |
| `timeoutMs` | 可选，默认 25000 毫秒，可覆盖；这是应用时限，不是服务商上限 |

成功时返回完整的 API JSON，包含正文、模型、用量及其他字段，不提取或解析模型正文。失败时抛出异常：HTTP/API 错误附带 `status`，存在时保留 `code` 和 `retryAfter`；成功响应中的 JSON 解析错误、网络错误、取消和超时保留原生错误。模块不自动重试、等待限流或更换模型。

已于 2026-10-20 使用 `minimax/minimax-m3.1-flash:free` 在 Node.js 和实际 Edge 155 扩展环境完成短文本联调，均取得回复正文、完整响应和用量信息。Haiku 5.5 在当次联调中返回 HTTP 402（额度不足），成功生成尚未验收。

当前侧边栏仍运行本机演示。模型路由、插件内 Key 管理、素材持久化和任务接入留到后续；图片和视频理解尚未联调。

## 开发检查与打包

仅开发工具需要 **Node.js 20 或更新版本**，无需安装依赖。在项目根目录执行：

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run package
```

- `check`：检查 JavaScript 语法、本地模块与页面资源、HTML ID 和标签引用、版本号及扩展权限。浏览器交互行为需另行实际验证。
- `test`：使用 Node.js 内置测试验证 LLM 请求、完整响应、错误、取消、超时和并行隔离；测试使用模拟请求，不消耗 API 额度。
- `package`：在 Windows 下将扩展文件和根目录安装说明打包到 `releases/autoreply-edge-frontend-v0.3.1.zip`，文件名随插件版本号变化。

`releases` 为本地生成目录，`output` 用于本地界面截图与验收记录，均不随源码提交。

## 权限

扩展申请 `sidePanel`、`storage`、`alarms`、`tabs`、`scripting`，以及 HTTP/HTTPS 网站访问权限，用于侧边栏、本机保存、任务唤醒、固定来源校验和网页浮标。

侧边栏中的前端模拟不需要服务器、API 密钥或额外账号。独立 LLM 请求模块的联调由调用方提供 API Key。真实业务接入范围和后续待确认事项见 [产品定位](PRODUCT_POSITIONING.md)。
