# AutoReply

面向店铺运营的商品评价回复工具，通过 Edge 侧边栏管理评价素材、回复任务和待人工清单。

**当前版本：0.2.1 · 本机前端演示。** 使用原生 HTML、CSS 和模块化 JavaScript，无运行依赖、开发服务器或构建步骤。任务处理和英语回复均在本机模拟；真实店铺评价采集、回复发布、媒体理解、LLM 和按商品加载上下文尚未接入。

## 已有功能

| 功能 | 说明 |
| --- | --- |
| 评价输入 | 支持纯文字、纯附件，以及文字与图片／视频组合；可点击选择、拖拽和多文件添加 |
| 素材预览 | 图片缩略图、浏览器视频播放器、文件名与大小展示、素材移除和重新选择 |
| 任务控制 | 按添加顺序逐条模拟，运行期间新增的评价继续纳入；支持立即暂停、继续和结束 |
| 待人工清单 | 通过手动标记或演示样本，将需要人工处理的评价与原因单独展示 |
| 产品资料 | 保存产品名称、可选 SKU 和资料正文，支持增删改、跨窗口同步及编辑冲突提示 |
| 页面绑定 | 开始后固定来源标签页和完整网址，切换其他标签页不改变处理目标 |
| 多窗口运行 | 同一窗口最多占用一个任务，不同窗口可运行独立任务 |
| 悬浮入口 | 挂起或关闭侧边栏后，浮标跟随本窗口当前普通网页，显示进度与待人工数量，点击返回原任务 |
| 本机恢复 | 分别保存任务、回复和表单草稿，支持手动领取保存记录及一次性旧版记录导入 |

## 安装

需要桌面版 **Microsoft Edge 142 或更新版本**。项目已在 Windows 的 Edge 155 中进行安装与交互检查。

先获取源码：

```powershell
git clone https://github.com/kyle-1227/AutoReply.git
cd AutoReply
```

也可以在本仓库点击 **Code → Download ZIP** 后解压。

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 开启“开发人员模式”，选择“加载已解压的扩展”。
3. 选择项目中的 **`extension` 文件夹**，该文件夹直接包含 `manifest.json`。
4. 在扩展菜单中将 AutoReply 固定到工具栏。
5. 前往需要处理评价的普通网页，点击 AutoReply 图标打开侧边栏。

安装和运行插件无需安装 Node.js。详细操作及更新步骤见根目录 [安装说明.md](安装说明.md)。

## 开始一次演示

1. 在侧边栏核对“准备使用的页面”标题和网址。
2. 点击“载入演示评价”，或在“添加评价”中输入文字、添加图片／视频。文字与附件至少提供一项。
3. 点击“开始演示”，任务开始占用本窗口并绑定来源页。
4. 可以继续添加评价、切换标签页，或点击“挂起”收起侧边栏。
5. 需要人工处理的评价保留在“待人工”页；所有可自动处理的评价完成后，本轮结束并释放窗口。

产品资料入口位于右上角的“添加产品资料”。当前资料库供前端管理使用，尚未参与回复生成。

## 任务运行规则

| 操作或事件 | 结果 |
| --- | --- |
| 只打开插件 | 展示准备使用的来源页，尚未占用窗口 |
| 开始任务 | 固定任务 ID、来源标签页、窗口和完整网址 |
| 立即暂停 | 取消当前步骤，保留进度和窗口占用；继续时重新处理当前未完成项 |
| 挂起、原生 X、切换标签页 | 原任务保持当前状态，运行中的任务继续推进 |
| 同窗口其他标签页重复打开 | 显示“此窗口正在使用”，可点击“返回任务页” |
| 同一完整网址刷新 | 等待来源页恢复后接续，已完成评价保留 |
| 来源换网址、关闭或移到其他窗口 | 结束任务、释放占用并保存记录 |
| 自动完成或点击“结束任务” | 释放窗口，保留已完成结果和待人工评价 |
| 完全退出浏览器或重新加载扩展 | 未完成记录等待在明确的目标页手动恢复 |

浏览器内部页面、扩展商店等受保护页面可能无法显示浮标，原任务仍保留，可通过工具栏返回。任务推进依赖浏览器、电脑和来源页保持可用。

## 数据与窗口隔离

- 评价队列、示例回复、处理记录、评价草稿和产品表单草稿按任务分别保存。
- 图片／视频原文件及预览地址只保留在当前面板会话中；关闭后保留附件信息，重新打开需要重新选择文件才能预览。
- 产品资料库在同一浏览器个人资料内共享；保存时检查版本，避免其他窗口的旧编辑覆盖新资料。
- 不同窗口用于隔离任务。普通新窗口仍共享网站登录状态，不同店铺账号需要独立浏览器个人资料或已有隔离环境。
- 浏览器重启后，可在目标页打开插件，通过“保存的任务记录 → 恢复到此页”领取已有记录，再手动开始。

## 项目结构

```text
extension/                  可直接加载的扩展
  background.js             浏览器事件、消息、侧边栏与唤醒
  task-coordinator.js       页面归属、窗口占用与记录恢复
  task-runner.js            单个任务的顺序处理、取消与接续
  workspace-store.js        本机保存、共享产品库和旧记录导入
  model.js                  数据结构、状态判断与演示样本
  queue.js / ui.js          共用串行队列、界面元素与消息请求
  panel.html / panel.js / panel.css  侧边栏界面
  products.js / media.js    产品资料与素材预览
  floating-controller.js / floating.js  浮标调度与展示
  busy.html / busy.js       窗口占用提醒
  icons/                    本地图标
scripts/
  check.mjs                 静态检查
  package.ps1               生成安装 ZIP
安装说明.md                  安装、更新与使用步骤
PRODUCT_POSITIONING.md      产品定位与待确认需求
```

任务状态由 `TaskRunner` 统一修改；界面发送命令并展示快照。页面归属由协调器管理，处理目标与当前浏览页分离；暂停、结束和刷新通过执行代次使旧回调失效。共用逻辑集中在少量模块中，便于后续替换模拟处理部分。

## 开发检查与打包

仅开发工具需要 **Node.js 20 或更新版本**，无需安装依赖。在项目根目录执行：

```powershell
npm.cmd run check
npm.cmd run package
```

- `check`：检查 JavaScript 语法、本地模块与页面资源、HTML ID 和标签引用、版本号及扩展权限。浏览器交互行为需另行实际验证。
- `package`：在 Windows 下将扩展文件和根目录安装说明打包到 `releases/autoreply-edge-frontend-v0.2.1.zip`，文件名随插件版本号变化。

`releases` 为本地生成目录，按现有忽略规则不随源码提交。项目已清理旧测试文件与浏览器验收缓存，目前不提供 `npm test`。

## 权限

扩展申请 `sidePanel`、`storage`、`alarms`、`tabs`、`scripting`，以及 HTTP/HTTPS 网站访问权限，用于侧边栏、本机保存、任务唤醒、固定来源校验和网页浮标。

当前前端模拟不需要服务器、API 密钥或额外账号。真实业务接入范围和后续待确认事项见 [产品定位](PRODUCT_POSITIONING.md)。
